# ZHHZ_NEW v71：双屏上下方向修复

在 v70 全高清 DrawCall 优化包基础上，本版只调整主屏视频纹理的 UV 采样方向：

- 立面屏 `MI_MainScreen_V` 保持已验证的正向画面。
- 天花板屏 `MI_MainScreen_H` 增加同样的垂直采样翻转，修复飞机/海面上下倒置。
- 两路仍从同一时间零点启动并持续校正漂移，未改变屏幕几何、材质分辨率、光照、Twin 合批或碰撞配置。
- 版本缓存参数升级为 `v71-screen-uv`，避免浏览器继续使用旧模块。

该修复只影响两块主屏的采样方向，DrawCall 和全高清数据链路沿用 v70：20/20 高清区块、12 张 Lightmap superatlas、HLOD=0、默认 50 m Twin 空间格。
