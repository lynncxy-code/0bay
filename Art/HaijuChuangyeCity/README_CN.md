# 上海“海聚英才”创业城（概念重建）

此目录包含可导入 UE5.6 的 `Shanghai_HaijuYingcai_EntrepreneurshipCity.glb`，以及玻璃、白色金属、铜色入口、铺装和草地贴图。模型根据公开报道与用户提供的图片制作，采用比例化概念尺寸，重点还原双塔、中央连桥、玻璃幕墙、竖向遮阳构件和铜色入口。

## UE 导入

项目已启用 glTFRuntime。将 GLB 放入 Content 可访问目录，使用现有 glTF 导入/运行时加载流程；若需要编辑器静态资产，可在 UE 5.6 中通过 glTF/FBX 导入器转换为 Static Mesh，并保留 `Textures` 目录中的 PNG 作为材质源。

尺寸：整体约 118m × 92m 基地，主体高度约 60m。
